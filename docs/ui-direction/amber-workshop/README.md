# Amber Workshop UI 视觉方向

本目录保存 AIPicToModel 的统一视觉方向稿。它们用于约束后续前端实现，不是新增功能原型，也不改变现有业务流程。

全部方向稿统一为 `1600 × 900`，便于逐页并排评审和后续实现比对。

## 不可变约束

- AI Agent 是核心功能，默认永久常驻右侧，桌面宽屏基准宽度约 `380px`。不得自动折叠、被参数面板替换或降级为临时抽屉。
- 工作区的六个页签——图片主页、风格转化提示器、图像生成、目标提取、三视图、3D 模型生成——是完全平级的目的地。
- 六页签不得出现编号、连接线、箭头、锁定、完成勾选、进度或前后依赖含义。仅当前页签使用黄铜色文字和 `2px` 下划线或轻选中面。
- 严格保留现有操作、状态、结果、错误处理和业务闭环。允许重组信息层级，不允许以“简化界面”为由删除功能。
- 留白不必填满，但必须形成有意图的构图和清晰的视觉中心。

## 视觉 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg-canvas` | `#11100E` | 画布和应用背景 |
| `--bg-shell` | `#1A1815` | 顶栏、侧栏、Agent |
| `--bg-panel` | `#211E19` | 页面面板 |
| `--bg-control` | `#2A261F` | 输入与控件 |
| `--text-primary` | `#F4F0E8` | 主文字 |
| `--text-secondary` | `#AAA297` | 次文字 |
| `--accent-brass` | `#D9A441` | 当前页签与主操作 |
| `--accent-copper` | `#B8734A` | 生成物与辅助强调 |
| `--accent-agent` | `#4BC3A5` | Agent 与本地服务状态 |

建议使用细暖灰边框、`6–8px` 圆角和极少阴影。避免紫色主调、玻璃模糊、霓虹、高饱和渐变和装饰性仪表盘。

## 实现边界

- 使用现有 React 组件体系、CSS Grid/Flex、CSS Variables 和 Phosphor Icons。
- 不引入新的 UI 框架、定制图标体系、复杂动画或装饰性功能。
- 方向稿中的图片内容用于说明层级和构图；实现时应绑定现有真实数据、状态和操作。
- 正式开发每个页面前，应以当前组件和测试为功能清单逐项核对；视觉稿不能作为删除现有功能的依据。
