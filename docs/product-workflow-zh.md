# AIPicToModel 产品工作流

## 产品叙事

AIPicToModel 是面向 3D 资产交付的创作工作台。用户可以从任意已有素材或模型进入，不要求按固定步骤完成整条链路。

产品层由四个独立工作台组成：

| 工作台 | 用户目标 | 功能入口 |
|---|---|---|
| 素材工作台 | 管理输入、当前图片和版本 | 当前图片 |
| 创意定稿 | 分析内容与风格并生成可继续生产的图片 | 内容与风格分析、创意图生成 |
| 建模准备 | 提取建模主体并制作结构输入 | 建模主体提取、三视图制作 |
| 资产交付 | 生成或导入模型，完成检查、优化和导出 | 3D 模型处理 |

## 交互原则

- 四个工作台是并列能力域，不显示步骤编号、完成百分比或强制的前后关系。
- 用户可直接导入 GLB 进入资产交付，也可从图片进入任意创意或建模准备工具。
- 页面标题使用用户目标语言；三视图、GLB、FBX 等术语只在具体工具和结果说明中出现。
- 后台任务不锁定当前页面，用户可以在其他工作台继续整理素材。
- Agent 使用同一组工作台入口，不维护另一套隐藏流程。

## 内部模式映射

现有 `WorkspaceMode` 继续作为稳定的内部状态，不作为产品栏目名称：

| 内部模式 | 产品入口 |
|---|---|
| `image` | 当前图片 |
| `compare` | 内容与风格分析 |
| `prompt_image` | 创意图生成 |
| `target_extract` | 建模主体提取 |
| `multiview` | 三视图制作 |
| `model3d` | 3D 模型处理 |

`selection`、`candidate`、`task_waiting` 和诊断状态属于工具内状态，不增加顶层栏目。

## 命名约束

后续新增功能优先归入现有工作台。只有出现新的、可独立进入且拥有不同交付目标的能力域时，才新增顶层工作台；不得把 Provider 名、API 名或单个处理步骤直接升级为产品栏目。
